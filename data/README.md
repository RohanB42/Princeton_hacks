# Local data

Keep downloaded datasets and transcriptomes here locally; only this README is tracked.

The five planned OligoGym datasets are stored in `oligogym/97f5b9f58d9e445a8ecb0218037af7465c3708c0/` as the upstream compressed CSV and JSON metadata pairs, alongside `all_datasets_info.csv.gz`. The directory name is the pinned upstream Git revision. These 11 files are ignored by Git and were byte-verified against that revision. See `docs/data-and-provenance.md` for the dataset mapping and the TLR7/8 metadata conflict. The scientific integration and benchmark reproduction have not started.
